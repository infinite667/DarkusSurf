# Contributing

Contributions for legitimate privacy, usability, accessibility, documentation, reliability and authorized security testing are welcome. Keep scope explicit, document any network changes, avoid hidden background behavior, and include tests. Do not submit secrets, bridge lines, downloaded executables, personal data or code intended to facilitate abuse. Keep upstream license and copyright notices intact.

Run Go formatting and tests before submitting a change. Network changes require explicit opt-in, accurate protection status, rollback behavior and tests on a disposable VM before real-device use. Report security-sensitive issues privately as described in SECURITY.md.
