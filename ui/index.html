How to verify your browser

Each launch opens the official Tor Project connection check in the newly configured browser. Check that page, not an existing browser window. You can also visit an IP-check website in the new window. A successful launch is not proof of routing.

Normal browser windows should retain their normal IP. Close the launched browser windows before exiting DarkusSurf or reconnecting; new Tor sessions require a fresh launch.

Experimental browser proxy configuration, not enforced application isolation. Browser background traffic, extensions, DNS, WebRTC and UDP may behave differently. No OS firewall, arbitrary EXE routing or complete leak prevention. Use official Tor Browser for anonymity-sensitive browsing.
